## 2 快速部署步骤

展示基于Docker的快速部署步骤

### 2.1 首次部署
首次部署，需要我们制作docker镜像并上传至阿里云服务器。可按照如下步骤进行。

#### 2.1.1 制作docker镜像

切换到docker目录，执行如下命令。

```bash
docker build -t video_base:v1.0 .
```

#### 2.1.2 保存镜像

执行如下命令，保存镜像。

```bash
docker save -o video_base_v1.0.tar video_base:v1.0
```

#### 2.1.3 上传镜像至阿里云服务器

在本地执行scp命令，将镜像及`docker-compose.yml`文件上传至阿里云服务器。

```bash
scp video_base_v1.0.tar user@your-aliyun-server:/opt/
scp docker-compose.yml user@your-aliyun-server:/opt/
```

#### 2.1.4 登录阿里云服务器，部署服务

当远程连接好服务器后，执行如下命令，部署服务。  

```bash
cd /opt

# 加载镜像
docker load -i video_base_v1.0.tar

# 部署服务
docker-compose up -d
```

#### 2.1.5 验证服务是否正常运行

在浏览器上输入地址：http://182.92.97.169:3000/，能够打开视频剪辑网站

### 2.2 热部署

当我们已经在阿里云上部署有服务之后，想进行一次小的修改，此时就没有必要按照章节2.1来执行。可以直接登录阿里云服务器，直接修改容器中的代码，因为我们的项目是支持热部署的，修改完代码之后，保存就可以立即生效。

#### 2.2.1 前端服务代码修改

登录前端服务容器，进行修改保保存即可。

```bash
docker exec -it video_frontend bash

# 修改对应的代码文件，保存就生效
```

#### 2.2.2 后端服务代码修改

登录后端服务容器，进行修改保存即可。

```bash
docker exec -it video_backend bash

# 修改对应的代码文件，保存就生效
```

#### 2.2.3 热部署修改注意事项

- 当需要改动的代码仅仅几行的时候，可以直接在容器中修改，修改完毕后保存即可生效，无需重启容器。
- 当需要进行大量变动的时候，需要按照章节2.1进行，热部署方案不适用此场景
