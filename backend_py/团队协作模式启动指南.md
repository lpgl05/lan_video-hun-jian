# 团队协作模式启动指南

## 📋 部署说明

### 1. 环境要求
- Python 3.8+
- 阿里云OSS配置（必须）

### 2. 初始化步骤

#### 方式一：自动初始化（推荐）
```bash
# 进入项目目录
cd backend_py

# 运行初始化脚本
python init_directories.py
```

#### 方式二：手动创建目录
```bash
cd backend_py

# 创建必需的目录结构
mkdir -p cache/materials cache/metadata
mkdir -p outputs/clips outputs/download_audios outputs/download_videos
mkdir -p outputs/subtitle_ass outputs/subtitle_images outputs/tts_audio
mkdir -p logs downloads/posters
```

### 3. 环境变量配置

确保 `.env` 文件包含以下OSS配置：
```env
# 阿里云OSS配置（必须配置）
OSS_ACCESS_KEY_ID=your_access_key
OSS_ACCESS_KEY_SECRET=your_secret_key  
OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
OSS_BUCKET_NAME=your_bucket_name
OSS_REGION=oss-cn-beijing

# 性能优化配置
OSS_CONNECTION_POOL_SIZE=100
OSS_MAX_CONCURRENT_UPLOADS=12
OSS_PART_SIZE_MEDIUM=30
OSS_PART_SIZE_LARGE=80
OSS_READ_TIMEOUT=600
```

### 4. 启动项目
```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## ⚠️ 重要变更

### 团队协作模式特性：
1. **不再支持本地存储** - 所有文件必须通过OSS存储
2. **移除uploads目录依赖** - 解决"Directory 'uploads' does not exist"错误
3. **强制OSS上传** - 上传失败时返回错误而不是使用本地备选
4. **统一文件管理** - 所有素材统一通过OSS管理

### 从个人创作模式迁移：
- 不再需要 `uploads/` 目录
- 所有本地文件URL（http://127.0.0.1:8000/local-files/）将无法使用
- 必须重新上传所有素材到OSS

## 📞 常见问题

### Q: "Directory 'uploads' does not exist" 错误
A: 这是正常的，新版本已移除对uploads目录的依赖，直接启动即可。

### Q: 视频生成失败
A: 检查OSS配置是否正确，确保有OSS读写权限。

### Q: 之前的本地文件无法访问
A: 团队协作模式不支持本地文件，需要重新上传到OSS。
