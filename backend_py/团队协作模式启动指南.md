# 团队协作模式启动指南

## 📋 部署说明

### 1. 环境要求
- Python 3.8+
- 阿里云OSS配置（必须）

### 2. 初始化步骤

#### 方式一：自动初始化（推荐）
```bash
# 进入项目目录
cd backend_py

# 运行初始化脚本
python init_directories.py
```

#### 方式二：手动创建目录
```bash
cd backend_py

# 创建必需的处理目录（不包含uploads，使用OSS存储）
mkdir -p cache/materials cache/metadata
mkdir -p outputs/clips outputs/download_audios outputs/download_videos
mkdir -p outputs/subtitle_images outputs/tts_audio
mkdir -p logs downloads/posters
```

### 3. 环境变量配置

确保 `.env` 文件包含以下OSS配置：
```env
# 阿里云OSS配置（必须配置）
OSS_ACCESS_KEY_ID=your_access_key
OSS_ACCESS_KEY_SECRET=your_secret_key  
OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
OSS_BUCKET_NAME=your_bucket_name
OSS_REGION=oss-cn-beijing

# 性能优化配置
OSS_CONNECTION_POOL_SIZE=100
OSS_MAX_CONCURRENT_UPLOADS=12
OSS_PART_SIZE_MEDIUM=30
OSS_PART_SIZE_LARGE=80
OSS_READ_TIMEOUT=600
```

### 4. 启动项目
```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

## ⚠️ 重要变更

### 团队协作模式特性：
1. **完全OSS存储** - 上传的视频、音频、海报直接存储到OSS
2. **无本地uploads目录** - 彻底移除uploads目录依赖
3. **智能查重** - OSS上传时自动去重，避免重复文件
4. **统一文件管理** - 所有素材统一通过OSS管理和访问
5. **无本地存储回退** - 确保所有文件都在云端，便于团队共享

### 从个人创作模式迁移：
- ✅ 移除所有 `uploads/` 目录
- ✅ 移除本地文件服务挂载 
- ✅ 所有上传文件直接到OSS
- ⚠️ 之前的本地文件需要重新上传到OSS

## 🗂️ 缓存管理

### 自动缓存清理
系统会自动清理缓存，触发条件：
- 缓存大小超过 5GB
- 缓存文件超过 50个  
- 每24小时定期清理
- 7天过期文件自动删除

### 手动清理缓存
```bash
# 进入后端目录
cd backend_py

# 运行清理脚本
python 清理缓存.py
```

选项说明：
1. **清理过期文件** - 只删除7天前的文件
2. **强制清理所有** - 清空所有缓存（下次使用时重新下载）
3. **仅显示状态** - 查看当前缓存统计

## 📞 常见问题

### Q: "Directory 'uploads' does not exist" 错误
A: 这是正常的，新版本已移除对uploads目录的依赖，直接启动即可。

### Q: 视频生成失败
A: 检查OSS配置是否正确，确保有OSS读写权限。

### Q: 之前的本地文件无法访问
A: 团队协作模式不支持本地文件，需要重新上传到OSS。

### Q: cache/materials 目录有很多文件
A: 这是正常的处理缓存，会自动清理。也可手动运行 `python 清理缓存.py`。

### Q: 缓存占用太多空间
A: 系统自动限制最大10GB，超过会自动清理最老的文件。
