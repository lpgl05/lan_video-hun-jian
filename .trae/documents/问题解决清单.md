# 项目问题解决清单

## 1. 依赖安装问题

### 问题：缺失Python依赖包
**解决动作**：安装必要的Python包
- `pip install fastapi uvicorn`
- `pip install httpx python-dotenv`
- `pip install moviepy pillow edge-tts`
- `pip install aiofiles python-multipart`

### 问题：前端依赖缺失
**解决动作**：安装Node.js依赖
- `npm install` (安装package.json中的所有依赖)

## 2. 配置文件问题

### 问题：环境变量配置不完整
**解决动作**：配置.env文件
- 设置 `USE_OSS=False` (绕过OSS权限问题)
- 配置 `FASTGPT_API_URL` 和 `FASTGPT_API_KEY`
- 添加 `BASE_URL=http://127.0.0.1:8000`

### 问题：API路由重复前缀
**解决动作**：修复路由配置
- 移除routes文件中的重复`/api`前缀
- 统一在main.py中配置路由前缀
